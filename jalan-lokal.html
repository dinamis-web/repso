💻 Cara Menjalankan Repso di Komputer Lokal

Sebelum disebar atau di-deploy ke Vercel, pastikan tool Repso bisa lu buka langsung di komputer lu sendiri.

Metode Paling Gampang (Static HTML/CSS/JS):

  1. Buka folder tempat lu nyimpen file Repso.
  2. Cari file bernama index.html.
  3. Klik dua kali (double click) file index.html tersebut. File akan otomatis terbuka di browser Chrome, Safari, atau Edge lu.
  4. Coba uji coba generator jadwal fitness dan log tracker-nya untuk memastikan semua tombol dan tampilan berjalan mulus.

Metode Alternatif (Pakai Terminal / VS Code):

Kalau lu pakai Visual Studio Code, lu bisainstall extension Live Server atau jalankan perintah ringan di terminal:

npx serve

Lalu buka alamat http://localhost:3000 di browser lu.
