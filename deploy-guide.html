🚀 Panduan Deploy Repso (Web-App Fitness)

Ikuti langkah-langkah di bawah ini untuk menjalankan Repso di komputer lokal lalu publish ke internet pakai akun Vercel & GitHub lu sendiri.

0 Jalanin Lokal Dulu (Local-First) Wajib

Sebelum online, pastikan tool Repso berfungsi normal di laptop/PC lu:

  • Simpan file web-app Repso dalam satu folder khusus (misal: repso-app).
  • Buka file jalan-lokal.html di folder tersebut atau klik 2 kali file index.html utama untuk langsung mencobanya di browser.
1 Siapkan Akun Gratis

Lu butuh 2 akun gratis untuk menempatkan source code dan hosting web-app:

  • GitHub.com: Tempat nyimpen file web-app lu secara aman dan privat/publik (100% milik lu).
  • Vercel.com: Tempat naruh hosting web-app biar bisa diakses lewat internet secara gratis dengan domain .vercel.app.
2 Upload ke GitHub Lu

Biar Vercel bisa baca web-app Repso, masukkan kodenya ke GitHub:

  • Bikin repository baru di GitHub (misal nama: repso).
  • Upload file-file web-app Repso (termasuk index.html dan file config vercel.json) ke repository tersebut via web upload GitHub atau aplikasi GitHub Desktop.
3 Hubungkan ke Vercel & Deploy 1-Klik

Deploy web-app biar langsung online:

  • Login ke dashboard Vercel.com pakai akun GitHub lu.
  • Klik Add New... -> Project, lalu pilih repository repso yang baru lu bikin.
  • Biarkan settingan build otomatis (karena ini Static HTML/CSS/JS), langsung klik Deploy.
  • Tunggu 10 detik, dan... Selesai! Lu bakal dapet link gratis seperti repso.vercel.app.
4 Sambungin ke Sistem Penjualan (Scalev)

Karena Repso adalah produk web-app tool siap jual:

  • Pasang link checkout Scalev di tombol pembelian landing page.
  • Begitu pembeli sukses checkout, sistem otomatis mengirimkan akses link web-app Repso ke pembeli tanpa ribet kirim manual.
