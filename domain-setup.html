🌐 Panduan Pasang Domain Sendiri untuk Repso

Saat ini Repso menggunakan subdomain gratis dari Vercel (misal: repso.vercel.app). Kalau nanti lu sudah siap jualan serius dan mau pakai brand sendiri (.com atau .my.id), lu bisa beli domain sendiri.

💡 Estimasi Biaya Domain (Cek harga terbaru di provider pilihan):
- Ekstensi .my.id: Mulai dari ~Rp 15.000 - Rp 25.000 / tahun.
- Ekstensi .com: Mulai dari ~Rp 150.000 - Rp 200.000 / tahun.

Langkah Menghubungkan Domain ke Vercel:

  1. Beli domain di provider lokal tepercaya (seperti Hostinger, Niagahoster, atau Domainesia).
  2. Masuk ke dashboard Vercel -> Pilih project Repso -> Masuk ke menu Settings -> Domains.
  3. Masukkan nama domain lu (misal: pakairepso.com atau repso.my.id) lalu klik Add.
  4. Vercel akan memberikan catatan DNS Records (CNAME / A Records).
  5. Masuk ke panel domain tempat lu beli domain tadi, lalu masukkan DNS Records dari Vercel.
  6. Tunggu masa propagasi domain (biasanya 1 sampai 24 jam), dan web-app Repso lu sudah bisa diakses pakai domain sendiri!
