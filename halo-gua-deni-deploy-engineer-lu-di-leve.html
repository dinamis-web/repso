💻 2. jalan-lokal.html Buka ▾

Cara super gampang jalanin web-app di komputer lokal lu sebelum di-publish.

1. Simpan file index.html dalam 1 folder khusus.
2. Klik 2 kali file index.html atau jalankan di terminal:
npx serve
3. Buka http://localhost:3000 di browser.
🔒 3. kenapa-github-sendiri.html Buka ▾

Alasan kenapa wajib pakai GitHub & akun sendiri demi keamanan & kepemilikan 100%.

- Kepemilikan Penuh (100% Milik Lu)
- Keamanan Terjaga (Tanpa bagi password)
- Kontrol Update & Fleksibilitas Tinggi
⚙️ 4. vercel.json Buka ▾

Konfigurasi deploy Vercel khusus untuk static web-app Repso.

{
  "version": 2,
  "name": "repso",
  "builds": [],
  "routes": [
    { "src": "/(.*)", "dest": "/index.html" }
  ]
}

🌐 6. domain-setup.html Buka ▾

Panduan pasang domain murah (.com / .my.id) untuk branding jangka panjang.

1. Beli domain di provider lokal (Hostinger/Niagahoster).
2. Masuk Vercel Settings -> Domains -> Masukkan nama domain.
3. Atur DNS Records sesuai instruksi Vercel.

📖 Panduan & Tentang Repso

Cara Pakai Repso

1. Buka tab Generator untuk merancang jadwal latihan mingguan sesuai target lu.
2. Gunakan tab Tracker setiap kali latihan di gym untuk mencatat beban & repetisi.
3. Data tersimpan otomatis di browser menggunakan Local-First Storage.
